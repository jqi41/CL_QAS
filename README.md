# CL-QAS
Continual Quantum Architecture Search with Tensor-Train Encoding: Theory and Applications to Signal Processing

Our codes include CL-QAS experiments for ECG Signal Classification and Financial Time-Series Prediction. 

#### Installation

The main dependencies include *pytorch* and *torch quantum*

#### 1. Simulating experiments of CL-QAS for ECG Signal Classification
python cl_qas_ecg.py 

#### 2. Simulating experiments of CL-QAS for Financial Time-Series Prediction
python cl_qas_finance.py
